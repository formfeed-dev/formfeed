# Security

Please report vulnerabilities in these packages or in the Formfeed service privately, by email to
support@formfeed.dev with "Security" in the subject, or through
[GitHub's private vulnerability reporting](https://github.com/formfeed-dev/formfeed/security/advisories/new).
We confirm receipt within two working days and keep you informed until the issue is resolved.

Only the latest release of each package receives security fixes.
