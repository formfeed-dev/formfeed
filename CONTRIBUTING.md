# Contributing

Thanks for helping to improve Formfeed's packages.

## Issues

Bug reports and feature requests are welcome in
[GitHub Issues](https://github.com/formfeed-dev/formfeed/issues). Please include the package and
version, what you ran, what you expected and what happened. For a rendering problem, the template,
a small data sample and the render id help most. Questions about your account or billing go to
support@formfeed.dev.

## Pull requests

This repository is generated from Formfeed's main repository, where the packages are developed
together with the API. A pull request here is welcome: we review it, apply the change upstream with
you credited as co-author, and it arrives here with the next sync, at which point the pull request
is closed. Please keep pull requests small and include a test; `pnpm nx test <project>` runs the
tests of one package.

## Security

Please do not report vulnerabilities in public issues; see [SECURITY.md](SECURITY.md).
